# url-shortly

A URL shortener built as a portfolio project. It takes a long URL and
returns a short code generated by **Base62-encoding an auto-incrementing
database ID** — deterministic and collision-free by construction, unlike
random-string generation with collision retries.

## Features

- **Shorten a URL** — `POST /api/shorten` validates the input (must be a
  well-formed `http:`/`https:` URL) and returns a short code + short URL.
- **Redirect** — `GET /:code` resolves a short code back to the original
  URL and issues a `301` (permanent) redirect.
- **Click analytics** — every resolved redirect records a click event
  (timestamp, referrer, user agent) in Postgres, without ever blocking or
  failing the redirect itself if the write fails.
- **Static frontend** — a plain HTML/CSS/vanilla JS form at `/` for
  shortening a URL and copying the result, no build step required.

See [`context/architecture.md`](context/architecture.md) for the full
design (including a diagram) and the reasoning behind these choices.

## Tech Stack

| Layer | Choice |
|-------|--------|
| Runtime | Node.js v20.12 LTS, CommonJS |
| Framework | Express.js 4.19.2 |
| Frontend | Static HTML + vanilla CSS/JS |
| Database | PostgreSQL (source of truth) |
| Cache | Redis (reserved for the redirect hot path — not yet wired in) |
| Testing | Jest + Supertest |
| Linting/Formatting | ESLint 9 + Prettier 3, enforced via a Husky pre-commit hook |
| Containerization | Docker + Docker Compose |

## Running the Project

### Option A: Docker Compose (recommended — no local Postgres/Redis needed)

```bash
docker compose up -d --build
```

This builds the app image and starts three containers: `app`, `postgres`,
and `redis`. The app container automatically runs database migrations
before starting the server. Once it's up:

```bash
curl -X POST http://localhost:3000/api/shorten \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/very/long/path"}'
# => {"shortCode":"...","shortUrl":"http://localhost:3000/..."}

curl -i http://localhost:3000/<shortCode>
# => HTTP/1.1 301 Moved Permanently
```

Or open [http://localhost:3000](http://localhost:3000) in a browser for
the shorten form.

Tear down (and wipe the Postgres volume):

```bash
docker compose down -v
```

See [`context/DEPLOYMENT.md`](context/DEPLOYMENT.md) for environment
variables, manual production deploy steps, and troubleshooting.

### Option B: Run Locally

Requires a running Postgres and Redis instance (e.g. via
`docker compose up -d postgres redis`, or your own local installs).

```bash
npm install
cp .env.example .env   # fill in DATABASE_URL / REDIS_URL for your setup
npm run db:migrate
npm run dev             # nodemon, or `npm start` for a plain node process
```

## Testing

```bash
npm test                    # run the full Jest suite
npm test -- --coverage      # with a coverage report
```

Unit tests mock external dependencies (Postgres, Redis) and target
`src/lib/` and `src/services/`. Supertest-based tests exercise the HTTP
routes/controllers. See [`context/TESTING.md`](context/TESTING.md) for the
full strategy.

## Linting & Formatting

```bash
npm run lint          # ESLint
npm run lint:fix
npm run format         # Prettier — writes changes
npm run format:check
```

Both run automatically on every commit via a Husky pre-commit hook.
